# Motor da simulação

Esta pasta receberá a extração e adaptação gradual das regras de `docs/scripts.js`.
Nesta primeira entrega o motor ainda não foi migrado.

Regras de configuração, endereçamento, acesso, FIFO/LRU/Random, estatísticas e
snapshots devem funcionar sem `document`, elementos HTML ou temporizadores.
O motor executará um acesso por chamada; o controlador da interface coordenará
play, pausa, velocidade e microetapas.

Os testes serão introduzidos junto das regras, conforme #25–#28, #30 e #31.
Preservar os resultados corretos do Beto, corrigindo separadamente os defeitos
documentados. Identificar nos módulos adaptados a origem e a licença MIT.
